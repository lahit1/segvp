## Examples

### "Hello world!" example
```rust
// This is a "hello world" example
fn main()
    println("Hello world!")
```

### Variable declaration
#### Implicit & Manifest Typing
```rust
let a = 1
let b: i32 = 2
```
#### Tuples
```
let (c, d) = ["Test", 0.5]
```

### Iterations

#### For Loop
```rust
for let i i32=0; true; i++
    println("Index: " + i)
```

#### While Loop
```rust
while true
    render_game() // renders game
```
